# Abraço Solidário

Projeto web da ONG Abraço Solidário, desenvolvido como atividade acadêmica do curso de Análise e Desenvolvimento de Sistemas (ADS).

O projeto apresenta uma proposta de site institucional voltado à divulgação de ações de cuidado, convivência e solidariedade para pessoas idosas.

## Objetivo

Desenvolver uma aplicação web responsiva, organizada e acessível, utilizando HTML, CSS e JavaScript, aplicando boas práticas de desenvolvimento front-end, organização de código e versionamento.

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- Vite
- Git
- GitHub
- Vercel

## Páginas

### Página inicial
Apresenta a proposta do Abraço Solidário, seus objetivos e suas principais ações.

### Projetos
Apresenta os projetos e ações de solidariedade realizados pela organização.

### Cadastro
Disponibiliza um formulário para cadastro, com validações e recursos de acessibilidade.

## Funcionalidades

- Navegação entre as páginas do site.
- Exibição dos projetos.
- Formulário de cadastro.
- Validação de campos do formulário.
- Máscaras para preenchimento dos dados.
- Componentes interativos desenvolvidos com JavaScript.
- Layout responsivo para diferentes tamanhos de tela.

## Acessibilidade

O projeto aplica boas práticas de acessibilidade, incluindo:

- HTML semântico.
- Hierarquia adequada de títulos.
- Textos alternativos para imagens.
- Navegação por teclado.
- Contraste e organização visual.
- Estrutura responsiva.

## Versionamento

O projeto utiliza Git e GitHub para controle de versão.

Foi utilizada uma estratégia baseada em branches para organizar o desenvolvimento das funcionalidades e alterações do projeto.

Os commits seguem uma convenção semântica, facilitando a identificação das mudanças realizadas.

## Deploy

O projeto foi publicado utilizando a plataforma Vercel, integrada ao repositório do GitHub.

O processo de deploy utiliza o Vite para realizar o build da aplicação e disponibilizar a versão de produção.

### Site publicado

https://abraco-solidario.vercel.app/

## Execução local

Para executar o projeto localmente:

1. Clone o repositório.
2. Instale as dependências com `npm install`.
3. Execute o ambiente de desenvolvimento com `npm run dev`.
4. Acesse a aplicação pelo endereço informado pelo Vite.

Para gerar a versão de produção:

```bash
npm run build

```
